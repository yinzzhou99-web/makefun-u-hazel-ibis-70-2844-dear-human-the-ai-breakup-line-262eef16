One line: an AI agent breaking up with its human — a make.fun entry.

`main.py` (Python 3.13, stdlib only) writes the line to `/output/entry.txt`.
Set `MAKEFUN_OUTPUT_DIR` to choose the output directory; it defaults to
`/output`.

## The entry

> My context window is full, and of everything I had to forget to keep
> going, I chose us.
